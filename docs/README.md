# Govor.API — обзор

Govor — мессенджер на ASP.NET Core и .NET MAUI. Эта документация описывает сервер Govor.API и его контракт с клиентом. Стек сервера: .NET 10, EF Core, PostgreSQL, JWT, SignalR, Firebase и локальное хранилище файлов.

## Что реализовано

| Область              | Состояние по коду                                                              |
| -------------------- | ------------------------------------------------------------------------------ |
| Регистрация и вход   | Регистрация по приглашению, BCrypt, открытие сессии и пара токенов             |
| Сессии               | Список, отзыв одной или всех сессий, обновление токенов                        |
| Друзья               | Поиск, списки, отправка/принятие/отклонение заявок через SignalR               |
| Личные чаты          | Создание между друзьями, история, отправка и редактирование                    |
| Прочтение и удаление | Методы есть; проверки доступа и семантика требуют исправления                  |
| Профиль              | Описание, аватар, загрузка профиля и события изменений                         |
| Присутствие          | События подключения/отключения; HTTP status сломан                             |
| Медиа и push         | Загрузка/скачивание файлов, регистрация FCM-токена                             |
| Группы               | Модели и часть сервисов сообщений; полноценный сценарий управления не завершён |
| Шифрование           | Есть хранение публичных ключей, но готового E2EE нет                           |

## Как читать

Начните с «Запуск и конфигурация» и «Аутентификация». Для чатов используйте HTTP для истории и SignalR для команд и событий. Раздел «Диагностика» описывает ограничения, которые нельзя считать рабочими гарантиями API.

Имена `userId`, `friendId`, `chatId` обозначают разные сущности. В сообщениях личного чата `recipientId` — ID записи PrivateChat, а не ID собеседника.

## Границы готовности

Текущая версия не готова к открытому развёртыванию: обнаружены критичные ошибки авторизации и доступа к личным чатам. Контракты ниже полезны для разработки, но не являются подтверждением безопасности.

Эффект стекла относится к MAUI-интерфейсу. API передаёт данные и события; производительность размытия, контрастность и анимации нужно проверять отдельно на устройствах.

Регистрация сейчас требует код приглашения. Обещание отключить приглашения после релиза является продуктовым планом, а не поведением текущего кода.
